# 0.5.0-02 Bugfix: light theme shows black tab headers when Windows is in dark mode (PO item 4)

Status: done (implemented 2026-11-16; PO approval per the release brief) · Size: S · Builder: **Sonnet** · Depends on: –

## Problem
`MainWindow._apply_theme` (main_window.py:417) only calls `app.setStyleSheet(app_stylesheet(...))`. `app_stylesheet` (ui/theme.py:47) sets padding and the selected border for `QTabBar::tab`, but no background or text colour. With PyQt6 6.11 the native Windows style follows the system colour scheme, so unselected tabs, and possibly scrollbars, headers and menu bars, are drawn dark while the app palette is light.

## Requirements summary (draft, pending Q-02)
1. Light theme with Windows in dark mode: every tab header in the main `QTabWidget` and in dialogs has a light background (`panel_bg`/`frame`) and dark text (`text`). The selected tab keeps the accent underline.
2. Dark theme with Windows in light mode: the tab headers are dark. The theme always wins over the system setting.
3. The menu bar, table headers (`QHeaderView`) in the Design sheet and the dialogs, scrollbars and the status bar follow the theme as well.
4. Switching the theme at runtime updates everything without a restart.
5. The mockup and PNG export look unchanged. The mockup has its own palette.

## Affected modules
`passport_designer/ui/theme.py`, `passport_designer/ui/main_window.py` (`_apply_theme`), `passport_designer/__main__.py`.

## Steps
1. **[Sonnet] Fusion style:** in `__main__.py`, after creating `QApplication`, call `app.setStyle("Fusion")`. Fusion respects `QPalette` and stylesheets fully; the native windows11 style ignores parts of them.
2. **[Sonnet] Palette builder:** in `ui/theme.py`, add `def qt_palette(p: Palette) -> QPalette` with Window, WindowText, Base, AlternateBase, Text, Button, ButtonText, Highlight, HighlightedText, ToolTipBase, ToolTipText and PlaceholderText, built from the `Palette` fields.
   - `theme.py` sits in `ui/`, so importing PyQt6 there is allowed.
   - Keep the existing dataclasses Qt-free.
3. **[Sonnet] Apply the theme:** in `_apply_theme`:
   - Call `app.setPalette(qt_palette(p))`.
   - Call `app.styleHints().setColorScheme(Qt.ColorScheme.Light if p.name == "light" else Qt.ColorScheme.Dark)`. This is available in Qt 6.8 and later; guard it with `hasattr`.
   - Then set the stylesheet.
4. **[Sonnet] Stylesheet additions** in `app_stylesheet`:
   - `QTabBar::tab { background: {p.frame}; color: {p.text}; border: 1px solid {p.border}; }`
   - `QTabBar::tab:selected { background: {p.panel_bg}; }`
   - `QTabBar::tab:hover`
   - `QHeaderView::section { background: {p.frame}; color: {p.text}; }`
   - `QMenuBar`, `QStatusBar`, `QScrollBar` basics, and `QTableWidget { background: {p.panel_bg}; gridline-color: {p.border}; }`

## Tests
In `tests/test_ui_smoke.py`, offscreen:
- **`test_light_theme_tabs_light_under_dark_system`**
  1. Set a dark `QPalette` on the app to simulate a dark system.
  2. Create the `MainWindow` and apply the light theme.
  3. Grab `window.views.tabBar()` and sample the pixel at the centre of an *unselected* tab.
  4. Assert its luminance is above 0.7.
- **`test_dark_theme_tabs_dark`:** the mirror case, with luminance below 0.35.
- **`test_app_stylesheet_has_tab_background`:** pure string check for both palettes.
