# 0.5.0-03 Spec flags foundation: Opnemen and MinimaleDataset per attribute

Status: draft · Size: S · Builder: **Haiku** (step 3: **Sonnet**) · Depends on: –
Foundation for plans 04 (PO item 1) and 05 (PO item 2). No user-visible change on its own.

## Facts (4 PO spec files, wave-2/3a/3b/4)
- `Attributen`: the header is on row 2, with **H `Opnemen`** and **I `MinimaleDataset`** (one word, so `norm()` gives `minimaledataset`).
- Values are exactly `Ja`/`Nee` with no blanks. MDS=Ja always has Opnemen=Ja.
- Duplicate type+attribute rows exist with identical flags. Attribute names can have trailing spaces; `_text()` strips them.
- Today `_read_attributes` (spec_reader.py:140) keeps only `Nee` in `spec.excluded`, and MDS is dropped.
- Older files may use `In paspoort tonen` instead of `Opnemen`, or lack the MDS column.

## Requirements summary
1. `SpecModel` keeps, per object type and normalised attribute, `include: bool | None` and `minimal: bool | None`. `None` means the column or value is missing.
2. The MDS header is recognised as `MinimaleDataset` and `Minimale dataset`, case- and whitespace-insensitive.
3. `spec.excluded` keeps working exactly as before, derived from the same read, so `layout_engine` and the existing tests stay unchanged.
4. `SpecModel.merge` combines flags. Given two different values for the same (type, attribute), the **later source wins** and a warning is logged with both source names.
5. A spec without the MDS column loads without error and reports `has_minimal_flags == False`.

## Steps
1. **[Haiku] `models.py`**
   - Add `@dataclass(frozen=True) class AttributeFlags: include: bool | None = None; minimal: bool | None = None`.
   - Add the field `SpecModel.flags: dict[str, dict[str, AttributeFlags]]` with a `field(default_factory=dict)`.
   - Add `SpecModel.has_minimal_flags` as a property: any `minimal is not None`.
   - Add the method `SpecModel.flag(self, *, object_type: str, attribute: str) -> AttributeFlags`. It looks up `norm(attribute)` and returns `AttributeFlags()` when nothing is found.
   - Use bilingual docstrings.
2. **[Haiku] `spec_reader.py`**
   - Add `MDS_COLUMNS = ("minimaledataset", "minimale dataset")`.
   - In `_read_attributes`, find `mds_index` like `flag_index`.
   - Add the helper `_yes_no(value: object) -> bool | None` (`ja`→True, `nee`→False, anything else→None).
   - Fill `spec.flags[type_name][key]` and keep the existing `excluded` logic.
3. **[Sonnet] `models.py` `SpecModel.merge`:** merge `flags` with later-wins, and log a conflict with `log.warning` (sources from `other.sources`). Keep the `excluded` union, and remove a key from `excluded` when the later flag says `include=True`. Write this down in the docstring as a deliberate change.

- `test_missing_mds_column_gives_none`, and `has_minimal_flags is False`.

## Risks
- Memory is negligible: about 15k entries across 4 waves.
- The later-wins merge differs from today's union for `excluded`. This only matters when the same type appears in two loaded files; it does not happen in the current files.
