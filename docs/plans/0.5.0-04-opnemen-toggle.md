# 0.5.0-04 Opnemen toggle: show all fields or only "Opnemen = Ja" (PO item 1)

Status: draft · Size: S · Builder: **Haiku** (step 3: **Sonnet**) · Depends on: 03

## Current state
This feature already exists in part. The left-panel checkbox *Only attributes marked for the passport* (`flagged_check`, setting `design/only_flagged`, default on) feeds `LayoutOptions.only_flagged`. With it on, `layout_engine.py:92-95` drops attributes whose `Opnemen` is `Nee`. Toggling it rebuilds the designs (`main_window.py:880-893`). What's missing:
- The control is not visible where the PO works (Mockup and Design sheet).
- Its wording points at the old `In paspoort tonen` column.
- In "all" mode there is no way to see which fields are `Nee`.
- The export does not say which mode was used.

## Requirements summary (draft, pending Q-04a/b/c)
1. A checkable action **View → Only fields with Opnemen = "Ja"** (NL: **Beeld → Alleen velden met Opnemen = "Ja"**), shortcut Ctrl+Alt+O. Ctrl+Shift+O is already taken by *Add specification*. A matching checkbox sits in a small toolbar row above the Mockup and Design sheet views. Both stay in sync, and the old left-panel checkbox is removed (or kept in sync; see Q-04a).
2. **On:** only `Ja` fields appear in the Mockup, the Design sheet, the Excel export, the PNG export and the payload. This is today's behaviour.
3. **Off:** all fields appear. Per Q-04b, `Nee` fields are shown in muted grey italic in the Mockup and the Design sheet, with the tooltip `Opnemen = Nee in the specification`. The Excel export shows them in grey italic too.
4. The state persists (`design/only_flagged`, same key, so saved settings keep working). Toggling keeps the selected passport and object type.
5. The `_designer` metadata sheet records `only_included: true|false`.
6. Profile exclusions (`V3_EXCLUDED`) still apply in both modes.

## Affected modules
`ui/main_window.py` (`_build_menus`, `_build_ui`, `retranslate`, the `_on_flagged…` handler), `i18n.py`, `excel_export.py` (`sheet_layout`, `write_metadata`), `ui/mockup.py` (cell styling), and `layout_engine.py` when step 3 is chosen.

## Steps
1. **[Haiku] Action and checkbox**
   - Add `only_included_action` (checkable) in the View menu and a `QCheckBox` in a new view toolbar row above `self.views`. Both connect to the existing toggle handler, using `blockSignals` to avoid loops.
   - Remove `flagged_check` from the left panel.
   - i18n keys: `action.only_included` (en `Only fields with Opnemen = "Ja"`, nl `Alleen velden met Opnemen = "Ja"`) and `action.only_included_tip` (en `Off: show all fields from the specification; fields with Opnemen = "Nee" are shown in grey.`, nl `Uit: toon alle velden uit de specificatie; velden met Opnemen = "Nee" worden grijs getoond.`).
2. **[Haiku] Metadata:** add an `only_included` row to `excel_export.write_metadata`, passed from `MainWindow`.
3. **[Sonnet] Mark `Nee` fields** (only if Q-04b = mark them):
   - Add the helper `def excluded_labels(spec: SpecModel, *, tab: PassportTab) -> set[str]` to the new core module `passport_designer/dataset_flags.py` (shared with plan 05). It returns the normalised labels whose flag is `include is False` for **all** object types of the tab, resolving inherited types the way `LayoutEngine._source_type` does. Expose `_source_type` as a public `source_type()` or pass a resolver.
   - Add the keyword parameter `muted: set[str] | None = None` to `sheet_layout(tab, *, muted=…)`; `SheetCell` gets the font colour `808080` and italic. `write_tab` honours the font colour.
   - Add the keyword `muted: set[str] | None = None` to `PassportMockup.show_tab(..., *, muted=None)`; the value boxes and labels use `palette.muted` and italic. `render_pixmap` copies `_muted`.
