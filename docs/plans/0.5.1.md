# 0.5.1 Plan: rename passport tabs, menu review, usability

Status: done (implemented on branch cramor-devo-v051-rename-tabs-plan) · Base: 0.5.0

## Goal
1. Rename a passport tab from the passport list (right-click → *Rename passport…*).
2. Same action on the *Samenvoegadvies* (merge advice) page for a suggested group.
3. *Edit/Bewerken* menu item *Rename passport…* (with shortcut, e.g. F2).
4. Review menu placement; list usability improvements.

## Grounded findings
- Passport list: `main_window.py` `filter_list` (l.188), context menu `_show_filter_menu` (l.1534) only offers *Merge selected*. Items are `"{name} ({n}){⧉}"` (l.1408).
- Tab identity is **the name string**. It keys `self.overrides` (l.1077-1124, 1241-1257 persisted layout store via `_layout_key(name)`), `applied_merges` (name, members), bulk export jobs (`job.passport`, l.1808), per-tab deletions (l.1372), Excel sheet names.
- Merge suggestions: `merge_tree` (l.279), name from `suggest_name`; `apply_selected_merge` (l.1526) uses `suggestion.name`. Manual merge already has `MergeDialog` + `validate_merge_name` (`merge_advisor.py`: non-empty, ≤ `MAX_NAME`=50, unique case-insensitive).
- Edit menu now: Mark to verify, Delete, Delete all marked, Restore, | Undo, Redo.

## Design
- New `self.renames: dict[str, str]` (original/generated name → custom name), applied in `_rebuild_designs` after `apply_merges`; unrenamed tabs unchanged. For a **merged** passport the rename updates the `applied_merges` entry name instead (merge name is already user-chosen).
- Renaming migrates `overrides[old]` → `overrides[new]` (undoable via the existing undo stack) and the persisted layout store key, so layout edits are not lost.
- One reusable `RenameDialog` (QLineEdit, reuses `validate_merge_name` with all other tab names as `existing`; OK disabled on error; sheet-name limit check for Excel, ≤ 31 chars or auto-truncate warning).
- Entry points: (a) filter-list context menu, (b) Edit menu `action.rename_tab` (acts on current list selection; disabled with 0 or >1 selected), (c) merge tree context menu + (d) *Rename suggestion…* before **Apply** (changes `suggestion.name`; pending name kept while the threshold stays the same; reset when suggestions recompute).
- Rename persisted in session/profile the same way `applied_merges` is (cleared when a new spec loads, l.597/1001). Optional *Reset name* in the context menu.

## Steps
1. `merge_advisor.py`/new helper: pure `rename_tab` logic + name validation incl. sheet-name rule; tests.
2. `main_window.py`: `renames` state, `_rebuild_designs`, override/layout-store migration, undo/redo, `rename_tab_action` + F2, list and merge-tree context menus.
3. `ui/rename_dialog.py`; i18n NL/EN keys (`action.rename_tab`, `rename.title`, `rename.reset`, errors).
4. Verify bulk export, Excel export, payload, cross-ref use the new name.
5. Docs: CHANGELOG 0.5.1, README.md + README.nl.md (menu, shortcut table), version bump left to release manager.

## Tests (pytest)
- Validation: empty, too long, duplicate (case-insensitive), unchanged name OK.
- Rename keeps overrides/layout; undo restores; rename of merged tab updates `applied_merges`; rename survives `_rebuild_designs`.
- UI smoke: context menu has action, Edit-menu action enabled/disabled, EN+NL labels, exports use the new name.
- Merge-page rename applies the new name on **Apply**.

## Usability suggestions (not in the two requested features; pick which to include)
1. Double-click or F2 on a passport to rename; show renamed tabs with an indicator (like ⧉ for merged).
2. Passport list filter box (search) – the list is long on big specs.
3. Show full name as tooltip (list is narrow, names are truncated at 320 px).
4. Merge page: show a "name" column editable inline; context menu *Preview / Apply / Rename*.
5. Persist splitter size and window geometry (check `settings`).
6. Status-bar hint after rename/undo; Edit-menu undo text with the action name ("Undo rename").
7. Bulk-export panel: remember last selection per session.

## Risks
- Name is the primary key everywhere; missing one place (saved layouts, bulk jobs, annotations, Excel) loses data → central migration function + tests.
- Excel sheet names are limited to 31 characters and exclude `[]:*?/\`; `MAX_NAME` is 50.
- Persisted layout store entries from 0.5.0 stay valid (keyed by original name until renamed).

## Decisions (PO)
- Q1: renames are session-only, like merges.
- Q2: full menu reshuffle table approved.
- Q3: usability items 1, 2, 3, 4, 6 are in scope; 5 and 7 are out.
- Q4 (default, not yet asked): renaming to a name that equals another passport's name is blocked.
