# 0.5.0-10 "Verify with customer" marks: red text or delete, in the Design sheet (PO item 6, decision D4)

Status: draft · Size: M · Builder: **Sonnet** (UI and rendering), **Opus** (step 1 override model, step 4 import) · Depends on: 06 (importer), 07 (override model, undo, persistence)

## PO decision D4 (2026-11-16, verbatim)
"These [red text / green-filled cells] are fields that need to be double checked with the customer. It might be necessary to delete these later. This also has to be an option in the Design Sheet to mark these fields with red text or delete them altogether."

## Evidence
In the refined workbook `Paspoortinrichting Wave 2 5nov26.xlsx` (read-only, not in the repo):
- **Red font `FF0000`:** a block of fields at the end of Object informatie on 10 of 13 sheets (e.g. Leiding!A16:E22, 16 cells; Gemaal!A14:B24).
- **Green fill `92D050`:** on `Distributiegebied**`/`Stroomgebied` (Leiding!C27:D27).

Today `refined_import._rgb` reads fills only (`refined_import.py:152`), and `Cell` has no state, so both marks are lost on import.

## Requirements summary
1. **Mark a field.** Context menu on a field in the Design sheet:
   - **Mark: verify with customer** (NL **Markeren: controleren met klant**) toggles the mark. It also works on a multi-cell selection.
   - **Delete field** (NL **Veld verwijderen**) removes the field from this passport.
   - **Delete all fields marked for verification** (NL **Alle te controleren velden verwijderen**), from the section context menu and *Edit* menu. It asks first: `Delete N marked fields from passport "<tab>"?` (NL `N gemarkeerde velden verwijderen uit paspoort "<tab>"?`), with Cancel as the default.
   - Shortcuts: Ctrl+Shift+V (mark) and Del (delete the selection).
2. **Marked fields** are shown in **red text** (`C00000` in Excel and the Design sheet; `#e5484d` in the mockup, readable on both palettes and on the MDS tints of plan 05). They have the tooltip `Verify with customer` (NL `Controleren met klant`).
3. **Deleted fields** disappear from the Mockup, Design sheet, Excel, PNG and payload, because the Design sheet is leading (D6).
   - The Validation tab lists them as info: `Deleted by user: <field>` (NL `Verwijderd door gebruiker: <veld>`).
   - **Restore deleted fields…** (NL **Verwijderde velden herstellen…**) opens a checklist to bring them back at their generated position.
   - Undo (Ctrl+Z) also works.
4. **View toggle:** **View → Show "verify with customer" marks** (NL **Beeld → "Controleren met klant" tonen**), default on, persisted as `view/verify_marks`. When off, marked fields look normal in the views and exports, for clean screenshots (Q-10b).
5. **Import:** in a refined workbook, red font (`FF0000`, and any red with R ≥ 0xC0 and G, B ≤ 0x40) and green fill `92D050` become verify marks. The `**` remark stays linked (plan 06, pointer 15).
6. **Export round trip:** Excel exports write red text for marks, and the `_designer` sheet stores the marks and deletions. Export → import → export keeps them.
7. **Payload:** marked fields stay in the payload until they are deleted (Q-10a). Deleted fields are absent.
8. **Persistence:** marks and deletions are part of the plan 07 layout override (same autosave, *Save/Load layout*, undo stack).

## Affected modules
- **Core:** `passport_designer/layout_overrides.py` (from plan 07), `models.py` (no `Cell` change, see the design note), `excel_export.py`, `refined_import.py`, `payload.py` (only through the effective tab).
- **UI:** `ui/sheet_preview.py`, `ui/mockup.py`, `ui/main_window.py`, `i18n.py`.

## Design
- **Overrides:** extend `TabOverride` with `verify: set[str]` and `deleted: set[str]` (normalised labels). Bump the JSON `version` to 2, and still read version 1.
- **`apply_override`** removes deleted labels (leaving a hole that compacts the row) and returns `(tab, warnings, verify_labels)`.
- **No `Cell.style` field:** marks live beside the tab as a label set, like the crossref highlights, so `Cell` equality and the crossref stay untouched.
- **Signatures**
  - `def toggle_verify(override: TabOverride, *, labels: Iterable[str]) -> TabOverride`
  - `def delete_fields(override: TabOverride, *, labels: Iterable[str]) -> TabOverride`
  - `def restore_fields(override: TabOverride, *, labels: Iterable[str]) -> TabOverride`
  - `def verify_labels_from_import(refined: RefinedWorkbook, *, sheet: str) -> set[str]`
- **Rendering**
  - `excel_export.sheet_layout(..., *, verify: set[str] | None = None)` sets the `SheetCell` font colour.
  - `PassportMockup.show_tab(..., *, verify: set[str] | None = None)`.
  - `render_pixmap` copies `_verify`.
- **Fixed and repeater sections** (Actoren, Memo, Inwinningsinformatie) can be marked but not deleted cell by cell, because the iAsset payload codes depend on them. Deleting a whole user-added section is allowed.

## Tests
- **Core (`test_layout_overrides.py`)**

  - Deleting inside a repeater is refused.

- **Export (`test_excel_export.py`):** a marked cell has font colour `C00000`; the `_designer` sheet holds `verify`/`deleted`.
- **Import (`test_refined_import.py`):** a synthetic sheet with red-font and `92D050` cells gives those labels in `verify`. The round trip export → import keeps the marks.
- **UI (offscreen)**
  1. Right-click a field, choose *Mark: verify with customer*, and assert the `sheet_preview` item foreground is red and the mockup label is red.
  2. *Delete all fields marked for verification*: Cancel leaves everything; confirm removes the fields from the sheet and payload text.
  3. Ctrl+Z restores them.
  4. Switch the View toggle off and assert there is no red.
  5. Export a PNG with the toggle on and off and compare the pixels.

## Risks
- **Deleting is local only.** It changes the design and payload text, not iAsset, and it is undoable. The confirmation defaults to Cancel.
- **Colour clash:** the red text must not be confused with the crossref "not-in-spec" outline (`#e5484d`), which is an outline, not text. Optionally the Reviewer suggests a darker red for the mark.
- **Import detection of "red"** uses a tolerance. Theme colours or tints in other workbooks may be missed; each import reports how many marks it detected.
