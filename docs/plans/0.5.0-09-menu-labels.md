## Requirements summary (proposed labels)
| Key | EN new | NL new |
|---|---|---|
| `action.open` | `&Open Unafact specification(s)…` | `Unafact-specificatie(s) &openen…` |
| `action.add` | `&Add Unafact specification…` | `Unafact-specificatie &toevoegen…` |
| `action.load_ids` | `Load passport field &ID file…` | `Paspoort-veld-&ID-bestand laden…` |
| `dialog.open_spec` | `Open Unafact specification` | `Unafact-specificatie openen` |
| `dialog.add_spec` | `Add Unafact specification` | `Unafact-specificatie toevoegen` |
| `dialog.load_ids` | `Load passport field ID file` | `Paspoort-veld-ID-bestand laden` |

1. The File menu shows exactly the labels above in EN and NL. The keyboard accelerators (`&`) stay unique within the File menu. Shortcuts are unchanged: Ctrl+O, Ctrl+Shift+O and Ctrl+I.
2. **NL style** follows the existing pattern: noun first, verb last, with "…". Compound nouns take a hyphen after a proper name (`Unafact-specificatie`, as in `Veld-ID-bestand`). The wording `Paspoort-veld-ID-bestand` is accepted (D9).
3. **Sentence case**, as in the rest of the app: `Open Unafact specification(s)…` (accepted, D9).
